    What's real on this page

    Live answers from one source. Your conversation goes to a small server function that asks Claude, and Claude can only use the archive file behind this site — the same file the guide is built from. The three cards fill from that file too, so nothing on the right is made up.

    Real photos, real records. The photos come from Billi Pepa's own photo history and album artwork, with his captions. The video series Lamar is making is AI-made and is always called that.

    What it can't do. It can't play music, sell records or pass on messages. It points you to Bandcamp, Spotify, YouTube and the band's official site, thewildstarfires.com, for all of that.

    Private by design. The chat lives in this browser tab only and clears when you close it. Nothing you type is saved to an account.
